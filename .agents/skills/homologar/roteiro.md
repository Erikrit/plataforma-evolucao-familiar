# Roteiro de homologação

Linguagem de quem usa, dados fictícios, um resultado esperado por passo.

```markdown
## <ID> — <o que será confirmado>
- **Preparação:** conta e dados fictícios
- **Aparelho:** modelo / navegador
- **Passos:** 1. … 2. …
- **Esperado:** …
- **Status:** PENDING_HUMAN
- **Retorno:** quem / quando / resultado / observação
```

Cobrir o caminho principal, o acesso negado a quem não tem autorização, a falha de rede sem falso sucesso e a regressão mais próxima.
